# Controlled experiment record

All result files are generated by `python rl_asl.py --config <config> --evaluate-only`.
Evaluation uses 2,000 independently simulated samples at each of rSNR 10, 15, and 20; ATT errors are in seconds. `baseline/sac-v1` preserves the original notebook source.

| ID | Experiment | Main change | SNR-10 ATT RMSE | SNR-10 CBF RMSE | Decision |
|---|---|---|---:|---:|---|
| 001 | Baseline reproduction | Saved SAC + LM checkpoint | 0.1125 | 2.3827 | BASELINE |
| 002 | Coarse-grid + LM | Observable 21x21 initializer; no SAC action | 0.0781 | 2.0814 | PROMISING |
| 003 | Random-init LM only | Remove SAC but retain random start | 0.4722 | 10.3308 | REJECTED |
| 004 | Random-init SAC only | Disable LM | 0.1670 | 5.9004 | REJECTED |
| 005 | Grid resolution | 15x15 versus 31x31 initializer | 0.0777 (31x31) | 2.0928 | PROMOTED CANDIDATE |
| 006 | 31x31 multi-seed evaluation | Two extra held-out simulation seeds | 0.0783 / 0.0792 | 2.1673 / 2.1703 | VALIDATED |

The promoted method is not an RL result: the ablations show that a signal-based coarse initializer followed by LM is responsible for the improvement. It uses all five fixed measurements and does not address adaptive PLD selection.
